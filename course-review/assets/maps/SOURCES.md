# Map geometry

World: world-atlas 2, countries-110m.json, derived from Natural Earth.
https://cdn.jsdelivr.net/npm/world-atlas@2/countries-110m.json
https://github.com/topojson/world-atlas
Natural Earth data are public domain: https://www.naturalearthdata.com/about/terms-of-use/

U.S.: us-atlas 3, states-albers-10m.json, derived from U.S. Census boundaries.
https://cdn.jsdelivr.net/npm/us-atlas@3/states-albers-10m.json
https://github.com/topojson/us-atlas

Retrieved September 24, 2026. Simplified boundaries are navigation aids, not a statement about historical borders. The world map uses a simple cylindrical display; the U.S. file uses its supplied Albers projection and insets. No external map or tracking requests occur at runtime.
